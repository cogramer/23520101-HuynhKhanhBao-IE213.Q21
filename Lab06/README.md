## Mô tả

Tiếp tục từ Lab 05, hoàn thiện chức năng phân trang và tìm kiếm dữ liệu cho hệ thống Movie Reviews sử dụng React và MongoDB.

---

## Nội dung thực hiện

* Hoàn thiện chức năng pagination
* Hiển thị dữ liệu theo từng trang
* Thêm nút chuyển trang

---

* Tìm kiếm phim theo:

  * Title
  * Rating

---

* Hoàn thiện chức năng review:

  * Add review
  * Edit review
  * Delete review

---

* Cập nhật mã nguồn tương thích React Router v6
* Sử dụng React Hooks hiện đại:

  * useState
  * useEffect
  * useParams
  * useNavigate
  * useLocation

---

## Kết quả
